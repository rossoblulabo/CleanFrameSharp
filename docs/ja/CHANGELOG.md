# 変更履歴

[English](../../CHANGELOG.md) · 日本語

## 1.1.0

- アプリ自身のすべての画面、ダイアログ、状態表示に日本語／英語の切り替えを追加。インストール済みアプリ名は変更しません。
- プロジェクトの文書を両言語で用意。初心者向けのインストール手順、正しいユーザー補助の設定順、任意のサービス設定、AIによるコード制作の明記、動作報告のある機種とOSを追加。
- Googleランチャーを開く操作をホームボタン設定に集約。半透明の黄色い枠とOK／キャンセルの確認を追加。OKでは割り当てがオフになり、キャンセルでは変わりません。
- 左のフェード開始位置をSettingsのn付近に移動。日本語では同じ比率の位置に調整。色を薄め、ディザリングを有効にし、一定の割合で透明になるフェードを維持。

## 1.0.2

- Settingsの最初のtから、均等なフェードになるよう変更。
- 不要なリマッパーの説明を削除。ユーザー補助を直接開く操作を、手順のダイアログへ変更。
- Aboutを通常の文字と既定で選択された戻るボタンに整理。素材のクレジットは背景設定に維持。
- システム画面を全幅にし、重複したGoogleランチャーの操作を削除。説明文をAboutの末尾へ移動。

## 1.0.1

- 時計の後ろの暗い部分を削除。
- 左の暗い部分を設定ボタンの少し先までに短縮。プレビューも同じ描画を使用。
- 公開用ソース、匿名の著作権表示、第三者ライセンス、プライバシー、一般向けのWindows手順を用意。
- 個人の引き継ぎ情報や接続先を配布物から除外。

## 1.0

- リスト／ドック、背景、文字の太さなどを選べる機能。
- オフにして元に戻せる、任意のホームボタン割り当て。
- リモコンでのアプリ選択と並べ替え、パッケージ状態表示、素材のクレジット。
