# 新しいGitHubリポジトリとして公開する

[English](../../PUBLISHING.md) · 日本語

1. GitHubで空のリポジトリを作ります。確認中は非公開にしても構いません。名前はCleanFrameSharpなどを使い、元のCleanFrameとは別の非公式Androidアプリであることを明記します。
2. このソースフォルダーの**中身**をルートにアップロードします。app、gradle、Gradle wrapper、.gitignore、LICENSE、文書を含めます。ZIPだけを置くのではなく、コードを閲覧できる形にします。
3. 公開するのは、この確認済みフォルダーだけです。親の作業フォルダー、過去の引き継ぎ資料、診断、鍵、build、他の配布ファイルをまとめてアップロードしないでください。Gitの過去履歴は含めていません。
4. 実機確認が済んだら、v1.1.0タグでリリースを作ります。CleanFrameSharp-1.1.0.apk、公開用ソースZIP、SHA256SUMSを添付します。GitHubはタグからソースZIPを生成することもできます。
5. 変更履歴をリリース説明に使い、インストール・復旧ガイドへリンクします。他機種・別のファームウェアは未確認であること、非公式の移植・再実装であること、AIでコードを制作したこと、元の作者と素材のライセンスを明記します。
6. 将来のAPK更新も同じ非公開の署名鍵を使います。公開ソースに鍵やパスワードは含みません。鍵のバックアップはリポジトリと公開ファイルの外に保管します。
7. 英語版と日本語版をそろえて公開し、先頭の言語リンクが動くことを確認します。

フォルダーの準備だけではGitHubに何もアップロードされません。GitHubのコミットに記録される名前・メールアドレスを非公開にしたい場合は、ご自身のアカウント設定も確認してください。ソースから個人情報を除いても、アカウント自体が公開する情報は隠せません。
