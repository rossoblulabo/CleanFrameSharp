# 開発への貢献

[English](../../CONTRIBUTING.md) · 日本語

小さなIssueやプルリクエストで、利用者から見た変更点と確認方法を説明してください。IPアドレス、アカウント、機器の識別情報、未編集のログ、署名ファイルは公開しないでください。

リモコンだけでの操作、設定の保存、元のランチャーに戻す手段、API 29対応を維持してください。ユーザー補助を許可しなくても使えることが必要です。利用状況の送信、ネットワーク権限、特権コマンド、他のパッケージの自動変更は追加しないでください。パッケージの説明は機種依存の参考情報であり、どのテレビでも安全に無効化できる一覧ではありません。

[ビルド手順](BUILDING.md)の確認を実行してください。自動テストの結果とテレビ実機で見た結果を区別し、第三者のクレジットとライセンスを残してください。画面写真には公開壁紙と仮のアプリを使い、個人のアカウント情報を含めないでください。

UIと文書は英語・日本語の両方を更新します。自然な日本語を使い、アプリ名・製品名・コマンド・パッケージIDは必要なものをそのまま残します。インストール済みアプリの名前は翻訳しません。
