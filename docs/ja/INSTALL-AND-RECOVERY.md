# インストールと元に戻す方法（Windows）

[English](../../INSTALL-AND-RECOVERY.md) · 日本語

Windowsパソコン、テレビのリモコン、配布済みのAPKを使う手順です。Android Studioやroot化、パソコンの常時接続は不要です。元のランチャーはインストール・有効のまま残してください。

## 1. 必要なファイルを用意する

1. [GoogleのPlatform Tools（Windows用）](https://developer.android.com/tools/releases/platform-tools)をダウンロードします。
2. ZIPを右クリックし、「すべて展開」を選びます。
3. 展開先のplatform-toolsフォルダーを開き、adb.exeがあることを確認します。
4. このリポジトリのReleasesからCleanFrameSharp-1.1.0.apkをダウンロードします。
5. APKをadb.exeと同じフォルダーにコピーします。

2つのファイルを同じフォルダーに置くと、長いパスを入力せずにインストールできます。

## 2. テレビで開発者向けのデバッグを有効にする

1. テレビ本体の「設定」を開きます。
2. 「端末情報」を開きます。「デバイス設定」や「その他の設定」の中にある場合は、先にそのメニューを開きます。
3. 下の方にある「ビルド」または「ビルド番号」を選びます。
4. リモコンの決定ボタンを**7回**押します。「開発者になりました」などの表示が出たら止めます。
5. 設定に戻り、「開発者向けオプション」を開きます。ファームウェアによっては「その他の設定」や「デバイス設定」の中にあります。
6. 「USBデバッグ」をオンにし、確認画面の内容を確認して許可します。
7. 「ネットワークデバッグ」「ADBデバッグ」などが別にある場合は、それもオンにし、表示されたポート番号を控えます。

7回押すのは「端末情報」そのものではなく、その中の「ビルド」です。すでに開発者であると表示された場合は手順5へ進みます。他の開発者向け設定は変更しないでください。

このガイドはネットワーク経由のADB接続を使います。USBデバッグをオンにするとポート5555で接続できるテレビもありますが、メーカー独自の有効化手順が必要な機種もあります。USBデバッグをオンにするだけで必ずネットワーク接続できるわけではありません。後で接続が拒否された場合は、その機種で使えるネットワークADBの方法を確認してください。Android 10には、新しいAndroidのペア設定コード方式のメニューはありません。

## 3. テレビのIPアドレスを調べる

1. テレビとパソコンを同じ家庭内ネットワークにつなぎます。
2. テレビの「設定 → 端末情報 → ステータス」を開きます。
3. IPv4アドレスを控えます。例：192.168.1.50。
4. デバッグ機能に表示されたポート番号を使います。従来のネットワークADBでは通常5555です。

このガイドの**192.168.1.50:5555**は説明用の例です。すべてのコマンドで、ご自身のテレビのIPアドレスとポート番号に置き換えてください。ルーターのアドレスではありません。再接続などでテレビのIPアドレスが変わる場合があります。

## 4. PowerShellを開いて接続する

1. パソコンのエクスプローラーでplatform-toolsフォルダーを開きます。
2. ウィンドウ上部のアドレスバーをクリックします。
3. <strong>powershell</strong>と入力してEnterを押します。
4. 次の1行を実行します。

~~~powershell
.\adb.exe connect 192.168.1.50:5555
~~~

192.168.1.50:5555をご自身のテレビの値に置き換えます。.\は、PowerShellを開いたフォルダーを表します。

5. テレビに「USBデバッグを許可しますか？」と表示されたら、自分のパソコンからの接続であることを確認して許可します。
6. 次のコマンドで接続を確認します。

~~~powershell
.\adb.exe devices
~~~

テレビの行の末尾が**device**なら次へ進みます。unauthorizedならテレビの確認画面を許可します。offlineや接続拒否の場合は、先にIPアドレス、ネットワーク、デバッグ設定を確認してください。コマンドは1つずつ実行し、説明文は貼り付けないでください。入力待ちが>>になった場合はCtrl+Cで中止し、コマンドを1行で入力し直します。

## 5. インストール・更新する

1. 次を実行します。

~~~powershell
.\adb.exe -s 192.168.1.50:5555 install -r ".\CleanFrameSharp-1.1.0.apk"
~~~

IPアドレスとポート番号を置き換えてください。このAPKのパスは、PowerShellを開いたフォルダーにファイルがあることを意味します。別のバージョンならファイル名も変更します。同じ署名のAPKであれば、-rで設定を残したまま更新できます。先にアンインストールしないでください。

APKが別のフォルダーにある場合は、次のようにフルパスを指定します。

~~~powershell
.\adb.exe -s 192.168.1.50:5555 install -r "C:\TVApps\CleanFrameSharp-1.1.0.apk"
~~~

IPアドレス・ポート番号と、C:\TVApps\CleanFrameSharp-1.1.0.apkを実際の保存先に置き換えます。パスに空白がある場合も引用符で囲んでください。上の2つのインストール例は、どちらか一方だけを使います。

2. **Success**と表示されるまで待ちます。
3. テレビのアプリ一覧からCleanFrame Sharpを開きます。次のコマンドでも起動できます。

~~~powershell
.\adb.exe -s 192.168.1.50:5555 shell am start -n org.cleanframe.sharp/.MainActivity
~~~

変更するのはIPアドレスとポート番号だけです。org.cleanframe.sharp/.MainActivityは、そのままにしてください。

4. アプリ一覧、アプリの起動、設定、戻る操作を確認します。
5. 日本語にするには「Settings → Language / 言語 → 日本語」を選びます。インストール済みアプリの名前は、そのアプリがAndroidに登録している表示名のままです。

INSTALL_FAILED_UPDATE_INCOMPATIBLEと表示された場合は、既存のアプリと署名が異なります。同じ署名の更新版を入手してください。CleanFrameだけを削除すれば別の署名でもインストールできますが、CleanFrameの設定は消えます。削除する場合は先に元のランチャーに戻してください。標準ランチャーを削除する必要はありません。

## 6. 先にユーザー補助のサービスを有効にする

1. テレビ本体で**設定 → その他の設定 → ユーザー補助**を開きます。
2. 一番下の**サービス**まで移動します。
3. **CleanFrame Home button**を選び、オンにします。Androidの説明を確認し、この機能を使う場合に許可してください。
4. CleanFrame Sharpに戻ります。
5. **設定 → ホームボタン → ホームボタンの割り当てをオンにする**を選びます。
6. 「状態を更新」を選びます。
7. 別のアプリを開き、ホームボタンを1回押します。対応するファームウェアではCleanFrameが開きます。

このテレビ本体のメニュー経路は、動作報告のあったシャープ製テレビのものです。他機種では異なる場合があります。テレビのサービスを有効にしてから、CleanFrame内の割り当てをオンにしてください。他のホームボタン変更アプリと併用しないでください。有効な間は、短押し・長押しのどちらでもCleanFrameが開き、元の長押し動作は置き換わります。この章を省略して、通常のアプリとして使うこともできます。

> **重要：Googleランチャーを開くと、ホームボタンの割り当てがオフになります。**
>
> **設定 → ホームボタン → Googleランチャーを開く**で確認画面のOKを選ぶと、元のGoogleランチャーを開き、CleanFrameの**ホームボタンの割り当てをオフ**にします。その後、ホームボタンではGoogleのホーム画面が開きます。
>
> 再びホームボタンでCleanFrame Sharpを開くには、CleanFrameの**設定 → ホームボタン → ホームボタンの割り当てをオンにする**を選んでください。自動ではオンに戻りません。「キャンセル」なら設定は変わりません。

## 7. 最後にデバッグをオフにする

1. 他のアプリからホームボタンでCleanFrameに戻れることを確認します。戻る、音量、入力切換など、普段使う機能も確認します。
2. 下の復旧手順を参照できるようにしておきます。
3. テレビの**設定 → 開発者向けオプション → USBデバッグ**をオフにします。「その他の設定」や「デバイス設定」の中に開発者向けオプションがある場合は、先にそこを開きます。
4. ネットワークデバッグやADBデバッグを別に有効にした場合は、同じ開発者向けメニュー、または有効化に使ったツールでオフにします。
5. ホームボタンでCleanFrameを使い続ける場合は、ユーザー補助の**CleanFrame Home button**と、CleanFrame内の**ホームボタンの割り当て**はオンのままにします。
6. PowerShellを閉じ、パソコンを切り離して構いません。
7. もう一度、別のアプリからホームボタンで戻れることを確認します。

必要な設定は以上です。ADBの常時接続、root化、別のホームボタン変更アプリ、システムパッケージの無効化は不要です。終了時にユーザー補助のサービスまでオフにしないでください。

## 元のランチャーに戻す

1. CleanFrameで**設定 → ホームボタン → Googleランチャーを開く**を選びます。
2. 確認画面を読み、OKを選びます。

ホームボタンの割り当てがオフになり、元のランチャーに戻ります。別途Androidの「既定のホームアプリ」を変更した場合は、その選択も元に戻してください。CleanFrameがその設定を変更することはありません。

CleanFrameを操作できない場合は、テレビ本体で**設定 → その他の設定 → ユーザー補助 → サービス → CleanFrame Home button**をオフにし、ホームボタンを押します。テレビの設定ボタンや設定メニューから操作してください。

デバッグが有効で接続済みなら、次でテレビの設定画面を開ける場合があります。

~~~powershell
.\adb.exe -s 192.168.1.50:5555 shell am start -a android.settings.SETTINGS
~~~

IPアドレスとポート番号を置き換えます。画面が開いたら、リモコンでサービスをオフにしてください。このショートカットに対応しないファームウェアもあります。デバッグをオフにしていた場合は、ADBを使う前に第2章の手順で再度有効にします。

最後の手段として、**CleanFrame Sharpだけ**をアンインストールできます。

~~~powershell
.\adb.exe -s 192.168.1.50:5555 uninstall org.cleanframe.sharp
~~~

IPアドレスとポート番号を置き換えます。CleanFrameの設定とユーザー補助サービスは削除されますが、他のアプリは削除されません。ホームボタンを押し、選択画面が出た場合は元のランチャーを選びます。復旧のために標準ランチャーを無効にしたり、システムアプリのデータを消去したりしないでください。
