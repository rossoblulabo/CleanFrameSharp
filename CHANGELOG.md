# Changes

English · [日本語](docs/ja/CHANGELOG.md)

## 1.1.0

- Added English/Japanese language selection for all app-owned screens, dialogs and status text; installed app labels remain unchanged.
- Rewrote all project guides in both languages, with beginner installation, corrected Accessibility setup order and optional service guidance. Added AI-development disclosure and the reported TV model/OS compatibility.
- Google launcher access is only in Home-button settings, with a translucent yellow frame and an OK/Cancel warning. OK turns Home interception off; Cancel does not change it.
- Moved the List fade start to the n in Settings (the equivalent proportional position in Japanese), reduced its tint and enabled dithering; the fade remains linear.

## 1.0.2

- Fade starts at the first t in Settings and changes evenly to the existing edge.
- Removed obsolete remapper references and replaced the Accessibility shortcut with a manual-directions dialog.
- About uses plain text with a top Back button selected by default; credits remain in Background.
- Privacy & system uses full-width rows without the duplicate Google launcher shortcut. The descriptive blurb is now at the bottom of About.

## 1.0.1

- Removed the separate dark shading behind the top-right clock; text shadow remains.
- Shortened the List layout’s left shading to end just beyond Settings, adapting to the utility row’s measured width. Settings previews use the same shading.
- Prepared public source, anonymous project attribution, separate third-party notices, privacy documentation and general Windows installation/recovery instructions.
- Removed private handover material and device-specific connection details from the distribution.

## 1.0

- List and Dock layouts with local background and typography options, including selectable lighter text weights.
- Optional direct Home-button Accessibility interception with a pause/recovery route.
- Remote app selection, Home app ordering, read-only package status and in-app credits.
