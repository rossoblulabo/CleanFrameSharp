# Contributing

English · [日本語](docs/ja/CONTRIBUTING.md)

Use a small issue or pull request that explains the user-visible change and how it was checked. Do not post device addresses, account details, identifiers, unredacted logs or signing files.

Preserve remote-only navigation, saved preferences, the original-launcher recovery route and API 29 compatibility. The launcher must remain usable without Accessibility. Do not add telemetry, network permissions, privileged shell execution or automatic changes to other packages. Treat package guidance as device-dependent reference information, never as a universal safe-to-disable list.

Run the checks in BUILDING.md. Explain which results are automated and which were observed on a real TV. Preserve third-party credits and licences. Screenshots should use the included public wallpapers and synthetic app fixtures, without personal account information.

Update both English and Japanese UI/documentation. Keep product names and executable commands intact, and use natural Japanese. Installed app names come from Android and must not be translated by CleanFrame.
